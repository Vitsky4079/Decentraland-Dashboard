Report & feedback

Found something? Tell the team.

Every report goes straight to the public Decentraland trackers on GitHub. A free GitHub account is required.

🐛 Report a bug

Something broken, crashing or not behaving as expected? This opens the Explorer bug report form with the right labels already set.

Report bug on GitHub

Tip: include what you did, what you expected, and what happened instead. Screenshots help a lot.

💡 Submit a feature request

Have an idea that would make Decentraland better? This opens the feature request form for the Explorer repo.

Submit request on GitHub

Tip: explain the problem your idea solves — it helps the team prioritize.

Before you report

  1. Check the Known issues page — your bug may already be tracked, and adding a 👍 reaction there helps more than a duplicate report.
  2. Try the Workarounds page if you are blocked right now.
  3. For account-specific problems (purchases, bans, lost items), contact official Decentraland support instead — public trackers are not the right place for personal account data.
